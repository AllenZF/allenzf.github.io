本教程介绍如何利用 Spike（RISC-V 模拟器）、OpenOCD（调试桥接）和 GDB/Telnet 进行软件调试，无需真实硬件。

🚀 启动调试流程

整个调试需要 三个终端窗口 同时运行。

终端 1：启动 Spike

参数解释：

  • --rbb-port=9824：让 Spike 在 9824 端口开放 remote bitbang 服务，供 OpenOCD 连接。
  • --pc=0x31503000：将程序计数器（PC）初始值设为 0x31503000（即您的程序入口地址）。
  • -m0x31503000:0x30000000：配置物理内存起始地址为 0x31503000，大小为 0x30000000（768 MiB）。
  • --halt：让 Spike 启动后立即暂停，等待调试器连接。
  • --p4：4个core.
  • riscv_bare_metal.elf：您的 RISC-V 裸机可执行文件。

提示：如果您的入口地址不同，请相应调整 --pc 和 -m 参数。若入口为默认 0x80000000，可省略 --pc。

🧰 常用调试命令

GDB 常用命令

命令 说明
target remote localhost:3333 连接到 OpenOCD
break <函数/地址> 设置断点
delete <编号> 删除断点
continue / c 继续执行
step / s 单步进入函数
next / n 单步跳过函数
finish 执行完当前函数
info registers 显示所有寄存器
print <变量> 打印变量值
x /<格式> <地址> 查看内存（如 x /10wx 0x80000000）
set var <变量>=<值> 修改变量
quit 退出 GDB

Telnet 常用命令

命令 说明
halt 暂停目标
resume [地址] 恢复执行（可指定起始地址）
step [地址] 单步执行一条指令（可指定地址）
reg 显示所有寄存器
reg <寄存器> 显示/修改寄存器值
mdd / mdw / mdh / mdb 按双字/字/半字/字节显示内存

bp <地址> 设置断点
rbp <地址> 移除断点
wp <地址> <长度> [r|w|a] 设置观察点（读/写/访问）
rwp <地址> 移除观察点
scan_chain 显示 JTAG 扫描链
riscv info 显示 RISC-V 调试信息
log_output log.txt 将后续的输出定向到log.txt中
poll 查询目标状态
help 查看帮助
exit 退出 Telnet 会话
shutdown 关闭 OpenOCD 服务器

❗ 常见问题与注意事项

问题 解决方案
OpenOCD 连接 Spike 失败 检查 spike.cfg 中的端口是否与 --rbb-port 一致；确保 Spike 已先启动。
GDB 无法连接到 3333 确认 OpenOCD 成功启动并输出 Listening on port 3333；检查防火墙是否允许。
程序运行到断点后无法继续 在 GDB 中执行 continue 或 Telnet 中执行 resume。
resume <地址> 后程序行为异常 直接跳转会破坏寄存器上下文，通常仅在非常清楚的情况下使用。
观察点设置失败 硬件触发器数量有限（如 riscv info 中的 Found N triggers），减少断点/观察点数量。
内存访问命令（如 mdw）无响应 确保目标已暂停（halt），或检查内存地址是否有效。
flash write_image 无法使用 Spike 模拟器没有 Flash，该命令仅适用于真实硬件。

📚 定制启动参数

  • 用 --pc 指定初始 PC 地址，直接跳转到程序入口。
  • 用 -m 设置物理内存范围（格式：起始地址:大小）。
  • 用 --halt 让模拟器启动后立即暂停，便于调试器接管。
  • 用 -p4 让模拟器启动4个core.

如果您的程序入口为标准的 _start 且位于默认复位向量（如 0x80000000），则可省略 --pc，Spike 会从默认的 0x1000 执行启动引导后跳转。

🎉 总结

通过 Spike + OpenOCD + GDB/Telnet 组合，您可以在纯软件环境中完成 RISC-V 程序的源码级调试，适用于嵌入式开发、操作系统实验和芯片验证。掌握这套流程，可大幅提升调试效率。

OpenOCD Telnet 调试命令速查表

通过 Telnet 连接 OpenOCD（telnet localhost 4444）后，可使用以下命令进行调试。

🎯 目标控制（含多核切换）

命令 说明 示例
targets 列出当前所有调试目标（如多核），显示编号和状态 targets
target <编号> 切换到指定编号的目标，后续命令作用于该目标 target 0
halt 暂停当前目标的运行 halt
resume 或 c 恢复当前目标的运行（可指定地址） resume
resume 0x80001000
reset 复位当前目标（若目标支持） reset
step 单步执行一条指令（可指定地址） step
step 0x80001000
poll 查询并显示当前目标的运行状态（暂停/运行中） poll

📋 寄存器操作

命令 说明 示例
reg 显示当前目标所有通用寄存器的值 reg
reg <寄存器名> 显示指定寄存器的值（如 pc, ra, sp） reg pc
reg <寄存器名> <值> 修改指定寄存器的值（需目标已暂停） reg pc 0x80000000

🧠 内存查看与修改

读取命令 写入命令 数据宽度 说明
mdd <地址> mwd <地址> <数据> 64 位（doubleword） 以 8 字节为单位读写内存
mdw <地址> mww <地址> <数据> 32 位（word） 以 4 字节为单位读写内存
mdh <地址> mwh <地址> <数据> 16 位（halfword） 以 2 字节为单位读写内存
mdb <地址> mwb <地址> <数据> 8 位（byte） 以 1 字节为单位读写内存

批量读写示例：mdw 0x20000000 10 表示从 0x20000000 开始连续读取 10 个 32 位数据；mww 0x20000000 0x12345678 5 表示从该地址连续写入 5 个 32 位数据（均写入相同值）。

🚧 断点与观察点

断点（Breakpoint）

命令 说明 示例
bp <地址> 在指定地址设置断点 bp 0x80001000
rbp <地址> 移除指定地址的断点 rbp 0x80001000

观察点（Watchpoint）

命令 说明 示例
wp 列出所有当前激活的观察点 wp
wp <地址> <长度> [r|w|a] [值] [掩码] 设置观察点。
• r：读取触发
• w：写入触发
• a：访问（读或写）触发（默认）
• 值：可选的触发条件值
• 掩码：与值配合，掩码为1的位表示“不关心”		 wp 0x20000000 4 w（监视写入）
wp 0x20001000 2 a（监视任何访问）
rwp <地址> 移除指定地址的观察点 rwp 0x20000000
rwp all 移除所有观察点 rwp all

💾 Flash 操作

命令 说明 示例
flash banks 列出当前所有已配置的 Flash 存储体（bank）及其编号 flash banks
flash info <编号> 显示指定 Flash 存储体的详细信息（大小、扇区、保护状态等） flash info 0
flash protect_check <编号> 检查并显示指定 Flash 存储体的保护状态 flash protect_check 0
flash write_image <文件> 烧录 ELF 格式文件（自动识别地址） flash write_image program.elf
flash write_image <文件.bin> <地址> 烧录裸二进制文件到指定地址 flash write_image program.bin 0x80000000
flash verify_image <文件> 校验 Flash 内容与文件是否一致 flash verify_image program.elf

🔍 JTAG 与调试信息查询

命令 说明 示例
scan_chain 显示当前 JTAG 扫描链中的所有 TAP（Test Access Port）设备及其状态，用于验证硬件连接和配置 scan_chain
jtag arp_init-reset 强制初始化 JTAG 扫描链，常用于唤醒因低功耗或异常而无法响应的 TAP 控制器 jtag arp_init-reset
riscv info 显示当前 RISC-V 目标的调试模块详细信息（触发器数量、XLEN、程序缓冲区大小、系统总线访问能力等） riscv info
transport list 显示当前 OpenOCD 版本支持的所有调试传输协议（如 JTAG、SWD） transport list
version 显示当前 OpenOCD 的版本信息 version

🛠️ 辅助与系统命令

命令 说明 示例
help 列出所有可用命令 help
help <命令> 查看指定命令的详细用法 help halt
exit 退出当前 Telnet 会话（OpenOCD 继续运行） exit
shutdown 关闭整个 OpenOCD 服务器 shutdown

💡 使用提示

  • 多核调试：使用 targets 查看所有 hart，再用 target <编号> 切换，后续命令只作用于当前目标。
  • 暂停要求：寄存器修改、内存写入等操作通常需要先执行 halt 暂停目标。
  • 命令补全：OpenOCD 支持 Tab 键自动补全命令（在 Telnet 中同样可用）。
  • 地址格式：所有地址均以十六进制表示，前缀 0x 可选（例如 0x80000000 或 80000000）。
  • 观察点资源：观察点依赖硬件资源，数量有限（通常 2~4 个），设置失败时请检查是否已用完。
  • resume 与 step 的地址参数：指定地址后，目标将从该地址开始执行（step 只执行一条指令）。此时通用寄存器的值保持为调用命令前的状态，与正常执行到该地址时的上下文可能不同，需谨慎使用。
  • riscv info 输出解读：Found N triggers 表示硬件触发器数量（用于断点/观察点）；dm.progbufsize 为程序缓冲区大小；dm.sb* 系列指示系统总线访问支持情况（0 表示不支持）；dm.authenticated 为 1 表示调试认证已通过。
